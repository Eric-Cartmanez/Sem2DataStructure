# Задача 26: ComposeWord

Написать функцию, проверяющую (возвращает логическое значение), можно ли составить строку word, используя только символы строки text. С учетом количества повторений каждого символа в обоих строках. Регистр учитывать не надо.

Вначале подается text, потом word.

Пример:

text = колбаса
сало - можно составить
облака - можно составить
барак - нельзя составить
лассо - нельзя составить
