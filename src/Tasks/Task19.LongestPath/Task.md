# Задача 19: LongestPath

На вход подается двумерный числовой массив. Написать программу (возможно, из нескольких функций), которая отыщет в массиве “цепочку возрастания” максимальной длины и распечатает адреса входящих в нее элементов. Соседние элементы в цепочке являются соседями по горизонтали/вертикали и в массиве.

Пример:

Массив (нулевая строка – верхняя, нулевой столбец – левый)

2 5 1 0

3 3 1 9

4 4 7 8

Маршрут по ячейкам: (1,2)— (1,1)— (2,1)— (2,2)— (2,3)— (1,3), по значениям: 1-3-4-7-8-9.
