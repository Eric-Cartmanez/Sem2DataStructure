# Задача 29: BiggestNumber

Найти в переданной входной строке самое большое число (числа могут быть вещественного типа). Числом считать последовательность соседних цифр или запятой. Если чисел нет вообще, то вернуть 0.

Например, для такой входной строки ответом будет 450:

"99DDAB7++0088UUQQ450 Z9Z"
