# Задача 24: UniqueLetter

Напишите функцию, которая ищет во входной строке первую уникальную букву, то есть такую букву, которая встречается в строке один раз. Регистр не учитываем, но возвращаем букву в правильном регистре.

Работаем только с буквами.

Если такого символа в строке нет, то вернуть точку.

Пример:

"Если вы не видели никогда Ивлета, советую вам отыскать его в Горячей долине."

Результат: 'у'.
