# Задача 28: NextBigNumber

На вход функции подается строка, состоящая из цифр, то есть представляющая число. Необходимо вернуть следующее большее число, составленное из этих же цифр. Если это невозможно, то вернуть -1.

Пример:

12  --> 21

513  -->  531

2184  -->  2418

222  -->  -1

931  -->  -1
